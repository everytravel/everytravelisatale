# Diario di viaggio — primo prototipo

Carica tutti i file in un repository GitHub pubblico. In Settings → Pages scegli Deploy from a branch, main, root.

I contenuti sono nei file `.md` (huahine.md, raiatea.md, ecc.). Puoi modificarli direttamente su GitHub. Le foto sono in `assets/images/`.

Questo è un prototipo: verifica la resa online e le didascalie prima della pubblicazione definitiva. Il file `.pages.yml` è una base da affinare per Pages CMS.
